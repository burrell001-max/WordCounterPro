# WordCounterPro

A free, private word and character counter. Plain HTML, CSS and JavaScript, no build step.

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `wordcounterpro`).
2. Upload `index.html` and `README.md`, or push them with git.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Your site goes live at `https://<your-username>.github.io/wordcounterpro/` in about a minute.
