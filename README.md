# WordCounterPro

A free, private word and character counter. Plain HTML, CSS and JavaScript with no build step.

Features: live counts, reading level, reading and speaking time, keyword density (1 to 3 words), word goal, daily activity, case conversion, undo/redo, auto-save, download as .txt, and a distraction-free "Go basic" view. Nothing you type leaves your browser.

## Files
- `index.html` – the whole app
- `404.html` – page shown for broken links
- `.nojekyll` – tells GitHub Pages to serve files as-is

## Publish on GitHub Pages
1. Open your repository, then **Add file → Upload files**.
2. Drag in every file from this folder (including `.nojekyll`; if it won't drag in, skip it, the site still works) and click **Commit changes**.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/WordCounterPro/`.

## Updating later
Open a file in the repo, click the pencil icon, edit, and click **Commit changes**. The site refreshes in about a minute.
